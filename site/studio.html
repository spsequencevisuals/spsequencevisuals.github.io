Set up social publishing

Connect your Facebook Page, Instagram, LinkedIn, X and TikTok accounts through Buffer. A website profile link and a publishing connection are separate.

  1. Connect your channels in Buffer ↗
  2. Create a personal API key in Buffer settings ↗
  3. Have the connection key added to this website’s secure settings. Social passwords and API keys are never entered in this studio.

Buffer requires a direct public HTTPS video URL. A private portfolio link cannot be fetched for publishing. Your Buffer plan determines how many accounts you can connect. TikTok releases are saved as drafts in Buffer so you can finish privacy and commercial disclosures before posting.

Behance and WhatsApp are available as profile/contact links in the next tab; they are not publishing destinations in this composer.
